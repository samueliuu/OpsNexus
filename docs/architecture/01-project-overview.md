# OpsNexus 项目概览

## 项目简介

**衡驭OpsNexus智能服务器运维系统** 是一款面向企业数据中心的 AI 驱动服务器运维管理平台，专注于多品牌物理服务器的全生命周期管理。系统整合了带外管理（BMC/Redfish）、资产台账、监控告警、自动化运维和 AI 知识检索五大核心能力，为运维团队提供统一的操作入口和智能辅助决策。

- **版本**: v1.1.0
- **许可证**: Apache 2.0
- **版权**: 南京诚臻晶睿信息技术有限公司

## 核心价值

| 能力 | 说明 |
|------|------|
| **统一带外管理** | 通过 Redfish/IPMI 标准协议，统一管理 Dell、HPE、Lenovo、华为、浪潮、H3C、曙光、超聚变 8 大品牌服务器 |
| **AI 知识助手** | 集成 RAGFlow 语义检索引擎，支持自然语言运维问答、SEL 事件码查询、固件兼容性矩阵查询 |
| **全链路监控** | 从 BMC 实时采集传感器数据，基于规则引擎自动评估告警，支持多渠道通知 |
| **自动化运维** | 任务编排引擎支持固件升级、巡检、配置部署等自动化场景，内置审批和重试机制 |
| **安全合规** | JWT + RBAC 权限体系、BMC 凭证加密存储、全操作审计日志、请求限流 |

## 功能模块

### 知识库

| 功能 | 说明 |
|------|------|
| AI 知识助手 | 自然语言问答，支持语义检索/结构化查询/混合查询三种模式 |
| SEL 事件码查询 | 按品牌、事件码、严重级别查询 SEL 事件含义和处理建议 |
| 固件兼容矩阵 | 按品牌、型号、组件查询固件版本兼容性和升级建议 |
| 对话管理 | 多轮对话历史记录、对话标题编辑、收藏管理 |

### 资产管理

| 功能 | 说明 |
|------|------|
| 数据中心管理 | 数据中心信息维护（名称、编码、位置、联系人） |
| 机柜管理 | 机柜信息维护，关联数据中心，U 高配置 |
| 服务器管理 | 服务器全属性管理，支持批量创建/更新/删除 |
| BMC 凭据管理 | BMC 连接凭据加密存储，支持 Redfish/IPMI/SNMP 协议 |

### 监控告警

| 功能 | 说明 |
|------|------|
| 监控仪表盘 | 服务器健康状态总览，CPU/内存/功耗实时指标 |
| 指标管理 | 自定义指标定义，支持 gauge/counter/histogram 类型 |
| 告警规则 | 灵活的阈值告警规则，支持条件组合和持续时间判断 |
| 告警事件 | 告警事件全生命周期管理（触发→确认→解决/抑制） |

### 带外管理

| 功能 | 说明 |
|------|------|
| BMC 连接测试 | 测试 BMC 连接并自动检测服务器品牌和型号 |
| 电源控制 | 远程开机/关机/重启，支持批量操作和分布式锁防并发 |
| 传感器读取 | 实时读取温度、风扇、电压等传感器数据 |
| SEL 日志 | 系统事件日志查询和批量确认 |
| 固件清单 | 查询当前固件版本和可用更新 |
| 硬件详情 | 并发获取 CPU、内存、存储、网络、电源、风扇等硬件信息 |
| KVM 远程控制 | 启动/终止 KVM 远程控制台会话 |

### 自动化运维

| 功能 | 说明 |
|------|------|
| 任务定义 | 创建固件升级、巡检、配置部署、自定义任务模板 |
| 任务执行 | 手动/定时/API 触发任务，支持审批流程 |
| 固件包管理 | 固件包上传至 MinIO，关联品牌和型号 |
| 巡检策略 | 定期自动巡检，按品牌/型号筛选目标服务器 |

### 审计日志

| 功能 | 说明 |
|------|------|
| 操作审计 | 自动记录所有写操作，支持多维度查询和 CSV/JSON 导出 |
| 通知记录 | 多渠道通知发送记录，支持失败重试 |
| 通知渠道 | 配置邮件、Webhook、钉钉、企业微信、飞书通知渠道 |

### 系统管理

| 功能 | 说明 |
|------|------|
| 用户管理 | 用户 CRUD，支持启用/禁用、密码管理 |
| 角色管理 | RBAC 角色定义，树形权限分配，内置角色保护 |
| 系统配置 | 键值对配置管理，支持敏感配置加密 |
| 通知渠道 | 多渠道通知配置（邮件/Webhook/钉钉/企业微信/飞书） |

| Lenovo | LenovoAdapter | XCC | 16+ |
| 华为 | HuaweiAdapter | iBMC | 11+ |
| 浪潮 | InspurAdapter | OpenRMC | 11+ |
| H3C | H3CAdapter | HDM | 9+ |
| 曙光 | SugonAdapter | BMC | 9+ |
| 超聚变 | XFusionAdapter | iBMC | 6+ |
